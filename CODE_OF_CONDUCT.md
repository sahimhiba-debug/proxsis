# Code de conduite

Ce projet adopte le **Contributor Covenant, version 2.1**
([texte français](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)).

En bref : on s'adresse à chacun avec respect, on critique les idées et pas les personnes, on accepte la critique
constructive. Le harcèlement, les propos discriminatoires, les attaques personnelles et la publication d'informations
privées sur une personne n'ont pas leur place ici, ni dans les issues, ni dans les pull requests, ni ailleurs au nom du
projet.

## Signaler

Signalez un comportement au mainteneur, [@sahimhiba-debug](https://github.com/sahimhiba-debug) (contact indiqué sur son
profil GitHub), ou à GitHub par **Report content**. Chaque signalement est traité avec discrétion ; les mesures
possibles vont du rappel à l'exclusion du projet, comme le prévoit le Contributor Covenant.
