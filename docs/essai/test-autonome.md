# Test autonome : une personne extérieure découvre Proxsis seule

Brief « à distance », § 14, étape 3. Le directeur de Flexsis recevra un lien, sans nous. Avant de l'envoyer, une personne
qui ne connaît pas le projet fait la même chose : elle ouvre le lien seule, sans explication, et nous observons ce
qu'elle comprend. Ce test ne mesure pas la valeur commerciale de Proxsis ; il vérifie que la visite se comprend sans
nous.

## 1. Qui, quand, comment

- **Qui** : une personne adulte qui n'a jamais vu Proxsis, idéalement habituée à décider dans une entreprise (direction,
  RH, commerce). Pas un membre de l'équipe, pas une personne de Flexsis.
- **Appareil** : le sien, celui qu'elle prendrait pour lire un e-mail professionnel (téléphone ou ordinateur : noter
  lequel).
- **Durée** : 5 à 10 minutes, puis 5 minutes de questions.
- **Lien** : l'adresse que recevra le directeur (premier écran, `/fr/` ou `/de/`), jamais une page de travail.
- **Observation** : de préférence en visioconférence avec partage d'écran, ou à côté d'elle, sans intervenir. Si elle
  pose une question pendant le test, répondre seulement : « Faites comme si nous n'étions pas là. » et noter la question.
- **Rien n'est enregistré sur elle** : pas de nom dans le compte rendu (un code, par ex. « T1 »), pas de vidéo gardée.

## 2. La consigne, à lui envoyer telle quelle

> Bonjour,
>
> Voici un lien : [adresse]. Ouvrez-le quand vous avez dix minutes, sur l'appareil de votre choix.
>
> Imaginez que vous dirigez une agence de travail temporaire en Valais. Vous recevez plusieurs présentations de
> services, dont celle-ci, et vous devez décider laquelle vaut un rendez-vous. Regardez-la comme vous le feriez
> vraiment : vous pouvez cliquer ou non, vous arrêter quand vous voulez.
>
> Nous ne vous expliquerons rien avant. Ensuite, nous vous poserons cinq questions courtes.
>
> Merci !

(Version allemande, à faire relire : « Guten Tag, hier ist ein Link: [Adresse]. Öffnen Sie ihn, wenn Sie zehn Minuten
Zeit haben, auf dem Gerät Ihrer Wahl. Stellen Sie sich vor, Sie leiten eine Temporärbüro-Filiale im Wallis. Sie
erhalten mehrere Präsentationen von Dienstleistungen, darunter diese, und entscheiden, welche einen Termin wert ist.
Schauen Sie sie so an, wie Sie es wirklich tun würden: Sie können klicken oder nicht und jederzeit aufhören. Vorher
erklären wir nichts. Danach stellen wir Ihnen fünf kurze Fragen. Vielen Dank! »)

## 3. Les cinq questions, après

Poser les questions dans cet ordre, sans reformuler, et noter les réponses mot pour mot.

1. En une phrase, à quoi sert Proxsis ?
2. Qu'est-ce qui change le lundi suivant ?
3. Les chiffres que vous avez vus, que mesurent-ils ? Qu'est-ce qu'ils ne mesurent pas ?
4. Qu'est-ce qui était réel, et qu'est-ce qui était fictif ?
5. Que feriez-vous maintenant, si vous étiez ce directeur ? (Et pourquoi ?)

## 4. La grille d'observation

À remplir pendant le test, une ligne par temps. Noter les faits, pas les impressions.

| Temps | Atteint ? (oui / non) | Durée approx. | A cliqué autre chose que « Continuer » ? (quoi) | Hésitation, retour, question | S'est arrêté ici ? |
|---|---|---|---|---|---|
| Premier écran | | | | | |
| 1 · Le premier lundi (carte, dossier, carnet) | | | | | |
| 2 · Le lundi suivant | | | | | |
| 3 · Une date | | | | | |
| 4 · Un seuil | | | | | |
| 5 · Une décision | | | | | |
| Conclusion | | | | | |

Points à cocher pendant le test :

- [ ] A compris, sans aide, que les entreprises sont réelles et les personnes fictives.
- [ ] A ouvert une source (« Voir la source »).
- [ ] A choisi une commune, une entreprise, une décision ou une date à lui (et non seulement l'exemple préparé).
- [ ] A remarqué la différence au lundi suivant (l'écartée ne revient pas, le rappel tombe à sa date).
- [ ] A lu l'aveu de la date (« une sélection plus compliquée n'a pas fait mieux qu'une règle simple ») et ne l'a pas
      pris pour une promesse de missions.
- [ ] A compris qu'un nouveau marché n'est pas une commande.
- [ ] A modifié une valeur du seuil, ou essayé « Deux fois moins ».
- [ ] A proposé un critère à « Nous continuerons si… ».
- [ ] A ouvert « Télécharger ma synthèse » ou « Préparer un e-mail ».
- [ ] Problème technique (affichage, lenteur, bouton qui ne répond pas) : lequel, sur quel appareil.

## 5. Ce qui compte comme réussi

Les quatre questions du critère final du film valent aussi pour la visite :

1. En dix secondes, la personne a-t-elle compris ce que Proxsis aide à faire ? (question 1)
2. Le passage de la publication au dossier était-il clair ?
3. Le lundi suivant montre-t-il une vraie différence ? (question 2)
4. La fin donne-t-elle envie d'essayer avec ses propres choix ? (question 5)

Un échec n'est pas caché : il dit ce qu'il faut corriger avant d'envoyer le lien.
